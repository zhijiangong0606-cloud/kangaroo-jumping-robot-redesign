## Recommended Assembly Steps

1. Open SolidWorks and create a new assembly.
2. Insert `BodySidePlate_verified.SLDPRT` twice. Place them at `Y = -8 mm` and `Y = +8 mm`.
3. Insert the five link parts twice, one set on each side.
4. Use concentric mates around the following joint points:
   - H0: `(0, 0)`
   - H1: `(-80, 60)`
   - H2: `(120, 60)`
   - A: approximately `(-42.4, 46.3)` in the shown pose
   - B: approximately `(45.0, 79.9)` in the shown pose
   - F: approximately `(-58.1, 231.0)` in the shown pose
   - T: `(200, -20)`
5. Insert the motor, drum, servo, and latch placeholder parts onto the body side plate.
6. Use the STL preview as a visual reference for the intended layout.

## Notes

- These parts are basic editable SolidWorks parts generated by API. They are intended as a first modeling base, not final manufacturing drawings.
- The current link parts are straight capsule links with M3 holes. Refine them later with fillets, lightening holes, bearing seats, and screw bosses.
- The body plate already contains the main pivot holes and approximate motor/servo mounting holes.
- For final mechanism animation, add mates manually and drive the H1 crank angle.
